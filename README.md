# tutorial-final
This repository was where I used to upload the work I produced whilst studying the [Vulkan tutorial](https://docs.vulkan.org/tutorial/latest).

I didn’t finish it because I realised that to learn Vulkan, I need to build something.

That ‘something’ will be Vulkan++, which is intended to be a step up in the evolution of the Vulkan API.

Not a replacement, but a library built on top of it, which, in my view, remedies the pitfalls of creating APIs in C.

It can be found here: [Vulkan++](https://github.com/F1STjd/Vulkan-pp).
